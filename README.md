# 📅 Calendario de Contenido — Iván Cristini

Calendario mensual de contenido para marca personal. Incluye estrategia completa para **Instagram** (Stories + Reels + Feed), **YouTube** y **TikTok**.

## 🔗 Ver en vivo

👉 **[calendario-ivan.vercel.app](https://calendario-ivan.vercel.app)** *(actualizar con tu URL real después del deploy)*

## 📋 Qué incluye

- **4 semanas** de contenido planificado día por día
- **~56 Stories** de Instagram con guion listo
- **8 Reels** (reutilizables en TikTok)
- **4 Videos de YouTube** con estructura y tiempos
- Instrucciones específicas de **cómo grabar** cada pieza
- Sistema de **5 pilares temáticos** con rotación semanal
- Leyenda visual con códigos de color por plataforma y formato

## 🚀 Deploy

Este proyecto se despliega automáticamente en **Vercel** cada vez que se hace push a `main`.

Para deployar manualmente:
1. Importar este repo en [vercel.com/new](https://vercel.com/new)
2. Framework Preset: **Other**
3. No cambiar nada más → Deploy

## 🛠️ Tecnología

- HTML5, CSS3, JavaScript vanilla
- Sin frameworks, sin dependencias, sin build
- Google Fonts: Instrument Serif, Space Mono, DM Sans
